# UTMods Roadmap

Status: current

## Priority 0: Usable and Reliable Normal Play

- Close current load, event, shared-hook, and package blockers.
- Complete Tier 0 and Tier 1 classification without changing honest evidence
  states.
- Reconcile source inventory provenance with the release candidate.
- Prove the happy-path single-player release profile.

## Priority 1: Evidence Compiler Migration

- Centralize schema, rendering, fingerprints, dependency graph, transaction,
  and status accounting.
- Migrate one representative generator from each structural family.
- Require byte-equivalent dual generation before replacing a legacy path.
- Replace repeated generic generator tests with parameterized compiler
  contracts.

## Priority 2: Mechanism Proof Reuse

- Introduce stable mechanism proof and obligation identities.
- Map exact consumers and parameter contracts.
- Collapse repeated presentation without losing the expanded audit mapping.

## Priority 3: Catalog Editing

- Evaluate a guarded review-grid import path for name, description, and cost.
- Require explicit intent-change approval, dry-run diffs, parser validation,
  dependent-file propagation, and rollback before allowing writes.
- Until then, the catalog remains generated and read-only.

## Deferred

- Exhaustive Tier 3 evidence after normal-play readiness.
- Additional locales.
- External mod integration without a verified current API.

Multiplayer and previous-save migration are product non-goals, not deferred
roadmap items.
